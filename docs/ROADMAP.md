# YuruAgent Roadmap

## Phase 0: Project Bootstrap

- Initialize repository structure.
- Define product scope and technical architecture.
- Prepare local development environment.

## Phase 1: Minimal Agent Runner

- Create, edit, and run a basic agent.
- Support prompt configuration and streaming responses.
- Store agent run history.

## Phase 2: Tool-Enabled Agents

- Add a tool registry.
- Support file, search, and browser tools.
- Record tool calls and errors.

## Phase 3: Workflow Workspace

- Add multi-step workflows.
- Support conditional branches, retries, and human confirmation.
- Visualize workflow execution state.

## Phase 4: Knowledge and Templates

- Add document upload and RAG.
- Provide reusable templates for research, browser automation, and developer tasks.
- Add evaluation cases for common workflows.

## Phase 5: Production Polish

- Add authentication.
- Add cost and latency dashboards.
- Add Docker Compose deployment.
- Publish project documentation and demo video.
